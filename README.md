# savas-oyunu-1
Written in Python Pygame, a little battle game project.

## Controls
W, A, S, D: Moving player

R: Gun choosing (normal)

TAB: Gun choosing (fast)

SHIFT: On swords: Sword Dash, On guns: Gun dash

Q: Deflecting arrow (only on sword)

T: Teleporting to mouse position

LEFT MOUSE CLICK: On swords: Sword normal attack, On guns: Shoot, On charms: Charm active effect use
RIGHT MOUSE CLICK: Throws throwable item if there are to mouse position

RIGHT CTRL: Takes screenshot of the game (saves on desktop)
